Runner d'équilibrage

Un utilitaire Python standalone permet de lancer des matrices de seeds sans Godot. Il écrit un rapport JSON et un résumé Markdown dans le dossier `reports/`.

Usage rapide:

```
python tools\balance_runner.py --seeds 1-100 --difficulty 1.5 --out reports/v0-9-balance
```

Le rapport JSON contient le détail des runs et le résumé (win rate, durée moyenne, dégâts moyens). Le Markdown est un aperçu lisible pour revue rapide.

Agrégation et tableau de bord

Un second outil permet d'agréger plusieurs rapports produits (par le simulateur ou la CI) et de produire un résumé JSON et un tableau HTML minimal pour revue rapide.

Usage:

```
python tools\analytics_aggregator.py --reports-dir reports --out-dir analytics
```

Le dossier `analytics/` contiendra `analytics_summary.json` et `analytics_dashboard.html`.

AI Director (Dynamic Difficulty)

Prototype d'un AI Director permettant d'ajuster dynamiquement la difficulté en fonction des métriques de campagne (win rate, durée, dégâts).

- Prototype GDScript: scripts/ai_director.gd — API testable headless.
- Runner Python: tools/ai_director_runner.py — consomme les balance_report.json et produit un timeline JSON des ajustements.

Usage rapide (runner):

```
python tools\ai_director_runner.py --reports-dir reports --out-dir director_out
```

Le timeline est écrit dans `director_out/director_timeline.json`.
