# Contrats de clients monstrueux

Chaque run est un chantier commandé par un client. Le contrat contient un biome, un objectif principal, des clauses optionnelles et une rémunération.

## Clients initiaux

- Maître Ossuaire, liche conservatrice : protéger un phylactère.
- Dame Cendrecroc, dragonne collectionneuse : protéger un trésor.
- Reine Velours-Noir : capturer les aventuriers vivants.
- Comte Sanguinor : produire une défense élégante et peu destructrice.

## Résultat de chantier

La satisfaction est calculée à partir des clauses respectées. Elle détermine :

- le paiement en ressources ;
- la réputation gagnée ;
- une note de D à S ;
- le déblocage futur de clients plus prestigieux.

Les contrats sont déterministes par seed et persistants pendant la run.
