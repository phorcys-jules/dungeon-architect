# Dungeon Architect v0.3.0-alpha

## Nouveautés

- Boucle complète run → récompenses → village → nouvelle run.
- Progression permanente de la tanière sauvegardée localement.
- Récompenses permanentes calculées à partir des vagues, captures, reliques et victoire.
- Écran de fin de run avec accès au village ou relance immédiate.
- Deck de salles influençant la génération procédurale.
- Choix roguelite déterministes entre les vagues.
- Synergies de build data-driven et effets affichables.

## Contrôles

- Souris : placer les défenses et utiliser les boutons.
- Bouton de phase : lancer l’invasion ou poursuivre la campagne.
- Porte : ouvrir ou fermer le passage central.

## Limites connues

- Direction artistique et équilibrage encore temporaires.
- Catalogue limité à trois salles et trois synergies.
- Le village ne contient pour l’instant que la tanière.
- La compatibilité des sauvegardes est limitée à la version 1.
