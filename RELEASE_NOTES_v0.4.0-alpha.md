# Dungeon Architect v0.4.0-alpha

## Nouveautés
- six salles spéciales supplémentaires ;
- quatre archétypes de monstres configurables ;
- quatre profils d’aventuriers : Voleur, Mage, Prêtre et Berserker ;
- Forge, Laboratoire et Cimetière avec progression ;
- six améliorations permanentes achetables ;
- trois nouvelles synergies, portant le catalogue à six ;
- mini-boss Capitaine paladin en fin de campagne ;
- migration automatique des sauvegardes v0.3 vers le format v2.

## Validation
- import Godot headless ;
- tests de contenu et de migration ;
- suite de non-régression ;
- export Windows automatisé.

## Limites connues
L’équilibrage, les animations et la présentation visuelle restent adaptés à une version alpha.
